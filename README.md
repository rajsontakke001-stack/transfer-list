# Transfer List React App

A simple React + Vite app with two lists. Select one or more items and use the arrow buttons to move them between lists. Each arrow button is disabled when its source list is empty or no items are selected.

## Run locally

1. Install Node.js if it is not already installed: https://nodejs.org/
2. Extract this ZIP file.
3. Open the extracted `transfer-list` folder in VS Code.
4. Open Terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Files

- `src/App.jsx` — React component and transfer logic
- `src/App.css` — component styles
- `src/index.css` — global styles
- `src/main.jsx` — React entry point
